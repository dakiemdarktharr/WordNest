Tạo bằng skill imagegen và công cụ image_gen tích hợp. Ảnh tham khảo được dùng làm ý tưởng hình học, không phải logo sản phẩm khác. File nguồn: build-resources/wordnest-source.png. Chuyển định dạng bằng Sharp qua npm run icon:build; ICO chứa các cỡ 16, 24, 32, 48, 64, 128, 256 px.
